# RetailOS PC Print Hub

RetailOS no longer requires a phone printing companion for the live store setup. The RetailOS API running on the controller PC owns the printer connection and serialises every raw ESC/POS job. Android phones only call the RetailOS receipt-print endpoint over the store network.

See [PC_PRINT_HUB.md](PC_PRINT_HUB.md) for installation and demo steps.
